# 自有理论的 3D nonlinear 秩测试

这个文件夹是一个独立的小分支，只用于回答一个问题：

> 将二维 nonlinear membrane+bending 程序扩展到三维螺旋线后，
> 当前构型下的切线刚度秩是否得到改善？

## 保持不变

- membrane 应变和内力公式；
- bending 应变和内力公式；
- 材料刚度与几何刚度的分解；
- load step + Newton–Raphson 迭代；
- 约束增广系统。

## 只改变

- 二维位移自由度改为三维位移自由度；
- 四分之一圆环参考几何改为 PCA/RKPM 螺旋线；
- RKPM 形函数矩阵和局部自由度索引扩展到 3 个分量；
- 在每个当前构型和 Newton 迭代中检查约束自由子空间的切线秩。

## 不属于本分支

- 不使用导师的 Rodrigues/director 迭代作为理论基础；
- 不修改 `26_RKPM_space_rod` 或 `RKPM_rod-main`；
- 暂时不添加新的 torsion 理论；
- 暂时不把 bending 改成两个独立物理分量。

## 秩检查

约束矩阵为 `C` 时，使用

```matlab
Z = null(C);
Kred = Z' * Kt * Z;
rank(Kred)
```

检查当前 nonlinear 总切线 `Kt`。原始未约束矩阵存在刚体模态并不自动表示模型错误，
因此主要报告 `Kred` 的数值秩、零空间维数和最小相对奇异值。
